# Edit style for BRAND NAME

The /shorts:edit skill reads this file before every edit. Add a rule every time an edit comes back wrong, in plain words, with the reason. Rules here win over the plugin's defaults.

## Look
- Cards: colours from config.json (`brand.card`). Change them there, not here.
- Captions: small, white with a black outline, low in the frame.

## Rules
- Hard cuts only between cards and face.
- Every short gets its own signature visual idea. Never the same card layout on every short.
- Never invent a number, a claim or a tool. Card text comes from what I say.
- Never use em dashes in on-screen text or captions.

## My rules (added from feedback)
- (example) 2026-01-10: captions were too big on the phone. Use size 46, not 52.
