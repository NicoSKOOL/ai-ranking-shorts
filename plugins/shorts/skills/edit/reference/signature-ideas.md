# Signature ideas that worked

Every short needs its own. Build it from what the speaker says; these are examples from a real 13-short batch, not templates to copy.

| Short was about | Signature idea |
|---|---|
| AI agents that buy for customers | Chat bubble "buy me running shoes", a bot slides into a mock store, cart gets +1, checkout bar fills step by step, "Approve $129?" sheet + cha-ching |
| A Google update: don't touch your site | A rankings line drawn with trimPath that jitters while a date strip fills, 7 day tiles ticking off, top 3 pages glowing |
| Google's AI answering for a business listing | A phone with a chat: customer asks, typing dots, bot answers from the listing (a line draws from the listing row), then a WHOOPS stamp with a glitch |
| Links moving up in AI answers | Mock AI answer box where source chips physically slide up into it, then an "official source" stamp lands with a glow |
| A day-of-week traffic pattern | Week strip where THU pulses each time the chart bump shows, click counters climbing |
| "Reviewed 439 sites, only 11 good" | A grid of dots: all fade grey except 11 that turn green with sparks |
| The 2-second test | A ring timer draining over 2 s with clock-ticking, ending on a phone + X: "LOST THE CALL" |
| Keyword tool vs Search Console | A scoreboard face-off: 10 on one side, the other counting up past 5,000 |
| Robots.txt blocking AI | Bot icons walk to a site, hit a lock, bounce back with a glitch; the robots.txt line types itself |
| SEO vs AEO vs GEO | Three different mini UIs (search results, an answer box, a chat), then all three sit on one foundation while a house builds |
| Copy-paste area pages | Pins drop on a map, the same page clones onto each town with only the name changing, eye-off "ignored", three X stamps |
| Websites now have two customers | A bot climbs a ladder one rung per step (answer, book, buy) |
| "Your site has 9 problems" | Nine warnings pop onto a site mock with a counter landing on 9; a too-long Google title truncates to "..." live |

## How to find one
1. What is the one image a viewer would remember from this short?
2. Is there a number? Make it count, fill, drain or compare.
3. Is there a process? Make something move through it.
4. Is there a before/after or a failure? Show it breaking.
5. Then list every concrete noun and give each a visual on its word.
